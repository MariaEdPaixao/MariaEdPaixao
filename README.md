## 💜 Sobre mim

Sou desenvolvedora de software formada em **Análise e Desenvolvimento de Sistemas pela FIAP**, com o coração no **backend em Java e Spring Boot** e um pé firme no **frontend com React e Next.js**.

Comecei cedo: fiz o **técnico em Desenvolvimento de Sistemas na Etec**, junto com o ensino médio, e desde então não parei de construir. Na FIAP, desenvolvi soluções em desafios com empresas como **Porto Seguro** e **Mottu**, passando por APIs, aplicações web e mobile, IoT com ESP32 e machine learning com Python.

No estágio, trabalhei criando interfaces e protótipos com foco em UX/UI, e é esse o meu diferencial: **penso a arquitetura do backend sem esquecer de quem vai usar o produto do outro lado.**
